## Narrow changes and active dialogue audit

`ConversationSystem._scrambleModel()` routes active losing-tribe post-immunity
strategy, gossip, idol, confrontation and accepted-counter callbacks into
`ScrambleConversation`; group alliance conversation uses `AllianceConversation`.
Generic legacy target/reassurance branches below those early returns are not the
active semantic scramble authority. No hidden timer path is reactivated.

The bounded truthful `voteStatement()` projection returns preference/lean,
provisional, actual pledge, accepted assignment, final expectation or unsettled
language. Group openings record that same topic/stance. Intentional cover uses
its audience-specific public target and does not describe private assignment or
write private intention. A weak wish to target the listener no longer invokes
blindside reassurance/decoy behavior. Player “I’m voting…” options still mean a
player-chosen promise, including explicit bluffs; adoption “commit” responses
still reflect an actual accepted commitment. “What have you heard?” remains a
report of owned stories, not a promise or objective ballot.

Tribal keeps its existing lean cap and gains a moderate provisional cap (.65),
while pledged/assignment/final input retains confidence-based strong authority.
No score terms, random ballot resolution, advantages or ritual are redesigned.

The optional adoption trace reports the score/outcome/guard already evaluated;
it adds no state, RNG draw or player-visible information. QA uses it to inspect
unsupported pitches, commitment resistance and listener choice. Production
ratings and adoption thresholds are unchanged.

## Diagnostic boundary

`captureConvergence()` snapshots each owner's intention, preference, maturity,
reason, known plans, valued known coalitions, accepted split and active backup
immediately before Tribal. Classification later uses this immutable snapshot,
even after the target is eliminated. A split, backup, valued competing plan,
protective holdout or uncertain vote is not an intentional rogue. “Rogue” here
means a mature deliberate intention outside that owner's meaningful known plans;
it never means merely disagreeing with the engine majority.

The comparison retains #352's configured initial coalitions/majority circumstances;
the separate mixed-preference matrix injects no final plans or ballots. Viable
player/NPC counterplay configures trust, physical opportunity and owned support;
responses and subsequent intentions use production systems. These controlled
capability runs do not establish an organic player survival rate.
